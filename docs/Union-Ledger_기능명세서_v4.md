# Union-Ledger (유니온 레저)

**AI 영상 처리 기반 대학 자치기구 결산 자동화 SaaS**

기능 명세서 (Feature Specification) v4.0 | 2026년 4월 9일

## 1. 사용자 역할 및 권한 체계

서비스는 3가지 사용자 역할을 가지며, 각 역할에 따른 권한이 시스템적으로 분리됩니다.

| 역할 | 주요 권한 | 역할 부여 방법 | 비고 |
|------|----------|--------------|------|
| **일반 학우** | 감사 완료된 결산안 웹 조회, 항목별 증빙자료 열람 | 대학 이메일 인증 회원가입 | 소속 단과대 결산안만 열람 |
| **재정담당자** | 결산안 작성, 증빙자료 업로드, OCR, 엑셀/PDF 생성, 거래내역 대조, 감사 제출 | 조직 관리자가 초대 코드/링크 발급 | 초대 없이 가입 시 접근 불가 |
| **감사위원** | 결산안 검토, 증빙자료 열람, 항목별 코멘트, 전체 승인/반려, 결과 발송 | 단운위에서 별도 초대 코드 발급 | 감사 독립성 보장 |

### 1-1. 회원가입 및 인증

모든 사용자는 대학 이메일(@konkuk.ac.kr 등)을 통해 본인인증 후 가입합니다. 가입 시점에서는 모두 '일반 학우' 역할이며, 재정담당자 및 감사위원 권한은 초대 코드를 통해서만 부여됩니다.

### 1-2. 조직(Organization) 구조

단과대 > 학과 학생회 단위로 '조직'이 생성됩니다. 학생회를 처음 등록하는 사람이 관리자(Admin)가 되며, 초대 코드를 발급할 수 있습니다.

### 1-3. 학기별 인수인계

전임 재정담당자가 '권한 이전' 버튼을 누르면 후임자 이메일로 승계 링크가 발송되고, 수락 시 권한이 이전됩니다. 과거 데이터는 조직에 귀속되므로 자연스럽게 승계됩니다. 전임자 잠수 대비 단운위 관리자의 강제 회수/재발급 권한이 필요합니다.

## 2. 재정담당자 핵심 워크플로우 (Step 1–5)

재정담당자의 실제 업무 순서를 기준으로 5단계로 구성됩니다.

| Step | 단계명 | 설명 |
|------|-------|------|
| **1** | 결산안 양식 등록 | 빈 결산안 엑셀(.xlsx) 업로드 → 셀 구조 파싱 → 템플릿 저장. 최초 1회. |
| **2** | 증빙자료 업로드 & OCR | 증빙 유형 선택 → 파일 업로드 → 유형별 처리(OCR/텍스트 추출) → 편집 카드에서 확인/수정 → 예산 항목 분류 → 장부 등록 |
| **3** | 거래내역서 업로드 | 은행 엑셀 업로드 → 증빙 추출 데이터와 날짜+금액 기준 1:1 자동 대조. 추후 은행 API 연동. |
| **4** | 대조 결과 확인 & 수정 | 매칭/불일치/누락 건을 색상별(녹/빨/노) 확인. 수동 수정 가능. |
| **5** | 결산안 엑셀 & 증빙 PDF | 버튼 하나로 결산안.xlsx + 증빙 PDF(가상 풀칠) 동시 생성 → 감사 제출. |

### Step 1: 결산안 양식 등록

학교/학과별 빈 결산안 엑셀(.xlsx)을 업로드하면 시스템이 셀 구조를 파싱하여 템플릿으로 저장합니다. 한 번 등록하면 다음 학기부터는 불필요합니다.

- **셀 매핑:** 초기 수동 매핑. 향후 자동 인식 검토.

### Step 2: 증빙 자료 업로드 & OCR

증빙 유형에 따라 처리 파이프라인을 분기합니다. 업로드 시 드롭다운으로 유형을 선택합니다.

| 증빙 유형 | 예시 | 업로드 형태 | 처리 방식 |
|----------|------|-----------|----------|
| **실물 영수증** | 카드결제, POS 영수증 | 사진 촬영 / 스캔 | 전처리 파이프라인 → OCR |
| **거래명세서** | 계좌이체 시 은행 발급 | PDF / 이미지 | PDF면 텍스트추출, 이미지면 OCR |
| **전자영수증** | 쿠팡, 네이버페이 등 | 스크린샷 / PDF | PDF면 텍스트추출, 이미지면 OCR |

모든 유형의 최종 추출 결과는 동일한 데이터 구조(날짜, 상호명, 금액, 결제수단)로 통일됩니다. 증빙 1건 = 1건 지출. 편집 카드: 왼쪽 원본 이미지 + 오른쪽 추출 필드(input). 다건 업로드 시 전체 리스트 + 개별 클릭 시 편집 카드.

- **예산 항목 분류:** MVP 수동 드롭다운, 추후 상호명 기반 자동 추천.
- **OCR 엔진:** PaddleOCR (Korean 모델). 여러 엔진 비교 후 한국어 영수증 인식률이 가장 높아 선정.

### Step 3–5: 거래내역 대조 → 확인/수정 → 출력

은행 엑셀 업로드 → 날짜+금액 기준 1:1 자동 매칭 → 대시보드에서 색상별 확인(녹/빨/노) → 최종 확인 후 결산안.xlsx + 증빙 PDF 동시 생성. 증빙 PDF는 유형 구분 없이 날짜순 정렬. 실물 영수증은 A4에 여러 장 배치, 거래명세서/전자영수증은 1페이지로 삽입.

- **MVP:** 은행 엑셀 업로드. 향후 은행 API 연동 예정.

## 3. 감사위원 모드

감사위원은 결산안을 직접 조회하여 감사를 시작합니다. 초대는 단운위에서 별도 발급하여 감사 독립성을 보장합니다.

### 3-1. 감사 플로우

1. 소속 단과대 결산안 목록 조회 (상태: 제출됨/감사중/승인/반려)
2. 결산안 선택 → 결산안 엑셀 + 거래내역 나란히 표시 (비교 검토 화면)
3. 각 항목 클릭 시 증빙자료 모달로 열림
4. 항목별 코멘트 작성
5. 전체 결산안 승인 또는 반려 결정
6. 감사 결과 재정담당자에게 알림 발송

### 3-2. 반려 시 프로세스

반려 사유 + 항목별 코멘트가 재정담당자에게 전달됩니다. 수정 후 '재제출' 버튼으로 감사 재요청하며, 수정 이력은 시스템에 기록됩니다.

---

## 4. 일반 학우 모드

감사 완료된 결산안만 공개됩니다. 소속 단과대의 결산안을 웹에서 항목별 조회할 수 있고, 각 지출 항목에 연결된 증빙자료(영수증, 거래명세서, 전자영수증)를 이미지로 확인할 수 있습니다. 결산안 엑셀 및 증빙 PDF 다운로드도 가능합니다.

### 6-2. OCR 파이프라인 아키텍처

본 프로젝트의 기술적 핵심입니다. OCR 엔진 자체는 오픈소스(PaddleOCR)를 사용하되, 열감지 영수증에 특화된 전처리 파이프라인과 한국 영수증 구조 파서가 본 프로젝트의 기술적 기여입니다.

#### A. 전처리 파이프라인 (4단계)

| Stage | 단계명 | 기법 | 목적 |
|-------|-------|------|------|
| **1** | Perspective Correction | Canny Edge → findContours → 4점 원근변환 | 비스듬히 촬영된 영수증을 정면으로 보정 |
| **2** | Background Removal | Morphology + Contour 기반 크롭 | 배경 제거 및 영수증 영역만 추출 |
| **3** | **Document Enhancement** | CLAHE + Bilateral Filter + Sauvola 기반 대비강화 | **열감지 용지의 불균일한 fading 복원 (★핵심)** |
| **4** | Adaptive Binarization | Gaussian Adaptive Threshold + Morphology Denoise | 영수증에 최적화된 이진화로 OCR 입력 품질 극대화 |

> ⚠️ **기술 정정 사항:** Stage 3의 화질 개선은 Dehazing(안개 제거)이 아닙니다. Dehazing은 대기 산란(Atmospheric Scattering) 모델 기반의 기술로, 열감지 영수증의 화학적 열화(코팅 분해로 인한 부분적·불균일한 대비 소실)와는 문제 자체가 다릅니다. 본 프로젝트는 DIBCO(문서 이미지 이진화 대회) 스타일의 Degraded Document Image Enhancement를 적용합니다.

**Stage 3 상세 — 열감지 영수증 열화 복원:**

열감지 용지는 열에 반응하는 화학 코팅으로 인쇄되며, 시간이 지나면 코팅이 화학적으로 분해되면서 글자가 사라집니다. 이는 안개(haze)처럼 전체적으로 균일하게 뿌옇게 되는 것이 아니라, 부분적으로 불균일하게 대비가 소실되는 현상입니다.

- **CLAHE (Contrast Limited Adaptive Histogram Equalization):** 이미지를 타일로 나눠서 각 타일별로 히스토그램 균등화를 수행하여 불균일한 fading을 보정합니다. clipLimit 파라미터를 영수증에 맞게 튜닝하는 것이 핵심입니다.
- **Bilateral Filter:** 글자 경계(Edge)는 보존하면서 열감지 용지 표면의 미세한 질감 노이즈만 제거합니다.
- **Sauvola 기반 대비 강화:** DIBCO 대회에서 검증된 문서 이진화 기법을 대비 강화에 응용합니다. 로컬 윈도우 내 평균·표준편차를 사용하여 불균일한 조명/fading에 강건하게 동작합니다. 순수 이진화 대신 소프트 대비 조정으로 OCR 입력 품질을 극대화합니다.

#### B. OCR 엔진: PaddleOCR

Baidu가 개발한 오픈소스 OCR로, CJK(한중일) 언어에서 오픈소스 최강 성능을 보여줍니다. DBNet(텍스트 검출) + SVTR(텍스트 인식) + 방향 분류기를 내장하고 있으며, 한영 혼용 영수증에서 특히 강력합니다.

- **OCR 엔진 선정 근거:** Tesseract(전통 OCR, 한국어 약), EasyOCR(PyTorch 기반, 양호), PaddleOCR(CJK 최강, 경량 모델 지원) 비교 후 PaddleOCR 선정. 성과 발표 시 3개 엔진의 정량적 인식률 비교 데이터를 함께 제시합니다.

#### C. 후처리 파서 (Korean Receipt Parser)

PaddleOCR의 raw output(비정형 텍스트 라인)을 정형 데이터(날짜, 상호명, 금액, 결제수단)로 변환하는 규칙 기반 파서입니다. 한국 영수증의 날짜 패턴(YYYY-MM-DD, YY/MM/DD), 금액 패턴(콤마+원), 카드번호 패턴, 상호명 위치 등을 규칙으로 파싱합니다.

### 6-3. 교수님 자문 영역

임창훈 교수님의 영상 처리 전공을 바탕으로 다음 영역에 대한 기술 자문을 받습니다.

1. **열감지 영수증 열화 복원(Degraded Document Enhancement) 알고리즘 자문:** CLAHE 파라미터 최적화, Sauvola 기반 대비 강화 기법 검증, DL 기반 Document Binarization 모델(DIBCO 스타일) 도입 타당성 평가
2. **Perspective Correction 및 Segmentation 최적화:** 비스듬한 영수증 보정 및 배경 분리 기법 자문
3. **IQA(Image Quality Assessment) 모델 도입:** 업로드된 이미지가 감사 증빙으로 유효한 품질인지 실시간 판별

### 6-4. 성과 측정 방법

전처리 파이프라인의 효과를 정량적으로 증명하기 위해 다음 실험을 수행합니다.

1. 동일 영수증 샘플(500장)에 대해 전처리 적용 전/후 PaddleOCR 인식률 비교
2. 동일 전처리 파이프라인 적용 후 Tesseract vs EasyOCR vs PaddleOCR 인식률 비교
3. Classical 기법(CLAHE+Sauvola) vs DL 기반 기법 성능 비교 (교수님 자문 후)
4. 측정 지표: 평균 신뢰도(confidence), 필드별 정확도(날짜/금액/상호명), 처리 속도

## 7. 전체 플로우 요약

1. **재정담당자:** 양식 등록 → 증빙자료 업로드 & OCR → 거래내역 대조 → 확인/수정 → 결산안+PDF 생성 → 감사 제출
2. **감사위원:** 결산안 조회 → 비교 검토 + 증빙 확인 → 항목별 코멘트 → 전체 승인/반려 → 결과 발송
3. **반려 시:** 재정담당자 수정 → 재제출 → 감사위원 재검토 (수정 이력 추적)
4. **승인 시:** 결산안이 일반 학우에게 자동 공개

## 8. MVP vs 추후 개발

| MVP (이번 학기) | 추후 개발 |
|---------------|----------|
| 대학 이메일 인증 회원가입 | SSO 연동 |
| 초대 코드로 역할 부여 | 단운위 강제 회수/재발급 |
| 수동 셀 매핑 | 셀 구조 자동 인식 |
| 증빙 3유형 (실물/거래명세서/전자) | 추가 유형 + 자동 판별 |
| PaddleOCR + Classical 전처리 (CLAHE+Sauvola) | DL 기반 Document Binarization (DIBCO 스타일) |
| OCR 결과 수동 확인/수정 | 신뢰도 점수 기반 선별 검증 |
| 예산 항목 수동 선택 | 상호명 기반 자동 추천 |
| 은행 엑셀 업로드 | 은행 API 연동 |
| 수동 인수인계 | 임기 만료 자동 알림 + 워크플로우 |
| 감사위원 직접조회 + 코멘트 + 승인/반려 | 감사 체크리스트 + 자동 이상탐지 |
| 반려 시 수정 후 재제출 | 수정 이력 diff + 버전 관리 |
| 웹 내 알림 + 대시보드 | 이메일/푸시 + 통계 대시보드 |
