# 발표 영상 실행 대본 — 영수증 파싱 시연

OCR 파싱 중간 과정을 화면에 띄워 시연하는 대본입니다. 명령 → 화면에
보일 것 → 나레이션 순서로 정리했습니다.

## 0. 녹화 전 준비

```bash
cd Union_Ledger-BE
# 터미널 글꼴 키우기 (가독성), 창 최대화
# 콘솔 한글 깨지면:  $env:PYTHONIOENCODING = "utf-8"   (PowerShell)
```

가능하면 **실제 영수증 이미지로** 돌리는 장면을 넣으면 가장 설득력 있습니다.
(PaddleOCR 설치 환경에서)

```bash
python -m union_ledger.tools.receipt_parse_trace --image samples/receipts/<영수증>.jpg
```

설치가 부담되면 이미 추출된 라인으로 파싱 과정을 재현해도 됩니다.

```bash
python -m union_ledger.tools.receipt_parse_trace --lines samples/receipts/goose_lines.json
```

## 1. 시연 흐름 (한 화면에 단계별로 출력됨)

명령을 실행하면 Stage 0 → 4가 순서대로 콘솔에 찍히고, 마지막에 결과
박스(`최종 추출 결제액 = 234,500 원`)가 나옵니다. 단계별로 짚으며 설명:

| 화면 | 나레이션 |
|------|----------|
| **Stage 0** raw 라인 | "PaddleOCR이 영수증에서 27줄을 인식합니다. 매장명·주소·항목·금액이 아직 구분 없이 섞여 있습니다." |
| **Stage 1** 금액 토큰화 | "천 단위 콤마가 있는 숫자만 금액으로 잡습니다. 수량 54 같은 숫자는 콤마가 없어 자연스럽게 걸러집니다." |
| **Stage 2** 라인 분류 | "각 줄을 결제·합계·세금·항목·메타로 분류합니다. 여기서 '카드결제'와 '합계금액'이 서로 다른 라벨로 갈립니다." |
| **Stage 3** 후보 그룹화 | "라벨별로 금액 후보를 모읍니다. 결제 234,500, 합계 854,500, 그리고 세금·공급가액은 부분 금액이라 따로 떼어 제외합니다." |
| **Stage 4** 결정 | "핵심입니다. 결산은 통장·카드 명세와 대조하므로 정답은 실제 출금된 카드결제 234,500원입니다. 합계 854,500은 분할결제 전 값일 수 있어 후순위입니다." |
| **결과 박스** | "그래서 최종 추출 결제액은 234,500원입니다." |

## 2. 일반성 시연 (하드코딩 아님을 증명)

```bash
python -m union_ledger.tools.receipt_parse_trace --lines samples/receipts/cafe_lines.json
```

> "이번엔 카드결제 라벨이 없는 영수증입니다. 결제 라벨이 없으니 규칙에 따라
> 합계금액 14,500원으로 자동 폴백합니다. 234,500에 맞춘 게 아니라 라벨
> 우선순위 규칙이 일반적으로 동작한다는 뜻입니다."

## 3. 산출물 보여주기 (제출물 연결)

```bash
# 단계별 JSON이 폴더에 저장됨
ls samples/receipts/reports/parse_trace/
```

> "각 단계는 JSON 파일로도 저장되어, 제출한 중간 산출물과 그대로 대응됩니다."

## 4. 예상 질문 대비 (Q&A)

- **Q. 왜 854,500을 안 잡고 234,500을 잡나?**
  → 결산 도메인에서는 실제 카드 출금액이 정답. 합계는 분할결제·할인 전
  값일 수 있어 후순위. (Stage 4 근거 그대로)

- **Q. 그 규칙이 이 영수증에만 맞춘 것 아닌가?**
  → 카페 영수증 시연으로 폴백 동작 제시. 규칙은 `결제 > 합계 > 항목 최댓값`
  으로 라벨 기반 일반 규칙.

- **Q. 세금·부가세 같은 큰 숫자에 안 속나?**
  → Stage 2에서 `과세물품가액·부가세·공급가액`을 별도 라벨로 분리해 후보에서
  제외. Stage 3의 `subtotal_excluded`에서 확인 가능.

- **Q. OCR이 숫자를 잘못 읽으면?**
  → Stage 0에 라인별 신뢰도(confidence)가 함께 남아 검수 가능. 낮은 신뢰도
  라인은 사람이 확인하는 흐름.
